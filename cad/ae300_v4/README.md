# AE300 R4 source

See [design notes](../docs/DESIGN_NOTES.md) for source provenance,
modelling assumptions, sensor mapping, usage and regeneration commands.

This GitHub handoff contains the latest R4 source, not the superseded R2/R3 packages.
Generated outputs go to `output/ae300_r4/` at the repository root and are ignored by Git.
Ready-to-open Blender and compressed STEP files are in `cad/models/`.
Run `node scripts/prepare-cad.cjs --step` from the repository root to restore STEP.
Historical output names in the design notes describe a full regenerated CAD delivery.
